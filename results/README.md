# Results

Every file here is generated by `scripts/run_experiment.py` and `scripts/analyze_results.py`. Each experiment writes raw runs (`*_runs.jsonl`, `*_runs.csv`) and summaries (`*_summary*.csv`, `*_summary.json`, `*_summary.svg`).

| Prefix | What it is |
|--------|------------|
| `v2_*` | Final results. 100 attacks in 10 categories, 4 defense conditions, 400 GPT-4o runs. The README numbers come from here. |
| `toolflow_*` | First benchmark. 52 attacks in 4 classes, 3 defenses, 156 GPT-4o runs. Too easy to separate the defenses; written up in `docs/toolflow_results_summary.md`. |
| `trackb_*` | Same 52 attacks under the `toolflow_active` architecture (156 runs). |
| `differentiation_*` | 60 attacks aimed at each defense's weak spot, 4 defenses, 240 runs; the step between the first benchmark and v2. Only `differentiation_runs.*` is this run: the summary files were overwritten by the v2 analysis and match `v2_summary*`. |
| `archive/` | Smoke tests, mock (no API) runs, and the original pilot (`runs.*`, `summary*`) that put email text straight into the prompt. Kept for the record. |
